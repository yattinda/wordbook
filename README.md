# wordbook

オフラインで使える英単語帳アプリです。単語の一覧・検索・詳細を、ネット接続なしで閲覧できます。自分用の**マイリスト**（名前付きリスト）に単語を保存でき、1語を複数リストに入れたり外したりできます。

## できること

- **単語一覧** — 見出し語、品詞、日本語訳などを一覧表示
- **検索・絞り込み** — 英語・日本語・定義での検索、品詞でのフィルタ
- **単語詳細** — 意味（日英）、発音（IPA）、コロケーション、類義語、例文
- **類似語** — 近い語へのジャンプ
- **マイリスト** — 名前付きリストの作成・改名・削除。単語詳細からリストへ追加／外し（複数リスト可）。一覧ヘッダーの「リスト」で棚を開き、リスト内は追加が新しい順・綴り／訳で検索・スワイプで外す。いずれかのリストに入っている語だけ、一覧カードに保存印を表示
- **クイズ** — 一覧の絞り込み、またはマイリストから、1語ずつ問題と答えを出す。意味は自分で確かめる。正誤や点数は保存しない。答えの画面からリストへ追加できる。リスト画面の「クイズ」で、そのリストだけを出題できる
- **設定** — 学習レベル用のバンド（既定は `core` / `upper` / `advanced`）、データソースのクレジット表示

一覧の既定では A1/A2 相当の `review` バンドは含めません。設定画面から変更できます。

## マイリストについて

- マイリストは端末内（アプリのローカル保存）にのみ保持します。ログイン・端末間同期・リストの共有はありません。
- 語彙データをアプリ側で更新した場合でも、マイリストは通常そのまま残ります。辞書から消えた語がリストに残っているときは、リスト画面で「この単語は見つかりません」と表示し、外すだけ可能です。

## 起動する

Node.js と npm が入っている環境で:

```bash
cd wordbook
npm install
npx expo start
```

Expo Go または開発ビルド（`npm run android` / `npm run ios`）で読み込みます。

語彙はアプリ同梱の SQLite（`assets/wordbook.db`）に入っています。リポジトリに DB が含まれていない場合は、配布用のデータ付きビルドを使うか、下記の開発向け手順で DB を用意してください。

## ライセンス・出典

語彙カードは複数のオープンライセンスソースの合成です。取り込み時に出典情報がある場合、アプリの**設定**画面および `assets/ATTRIBUTION.md` に、ソースとライセンスの概要を表示します。例文は Tatoeba（CC BY 2.0 FR）など、ソースごとの条件が適用されます。一部の日本語訳は機械補助で付与されている場合があります。

## 開発（最低限）

| もの | 用途 |
| --- | --- |
| Node.js + `npm` | アプリの起動・ビルド |
| Python 3（任意） | 語彙 DB の再生成（`npm run ingest`） |

語彙 DB を自分で作る場合:

```bash
npm run ingest
```

処理済みの語彙 JSONL（`words.jsonl`、任意で `neighbors.jsonl`）と、必要なら `ATTRIBUTION.md` を `--words` / `--neighbors` / `--attribution` で指定します。詳細は `scripts/ingest-dataset.py` のヘルプを参照してください。

一覧に「（訳なし）」や英語定義だけの行がある場合は、その意味に日本語訳が無い状態です。wordbook 単体では補完しません。語彙データ側で訳を足してから、再度 ingest してください。
